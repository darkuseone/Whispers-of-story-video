# Протокол обложек (Whisper of History / Ancient Whispers)

Как делать превью канала. С 19 сентября 2026 сетка **зафиксирована**
по эталонной ленте: огромный жёлтый Anton сверху, детализированный
16:9 кадр снизу. Паттерн меняет героя, не вёрстку.

Конвейер: `pipeline/covers.py`. Писать хуки и промпты —
`ИНСТРУКЦИЯ-ЧАТ.md`.

---

## Сетка канала (не ломать)

16:9, обычно 1280×720. Photoreal cinematic still. Не иллюстрация.

```
┌─────────────────────────────────────────────┐
│                                             │
│   NO DISTRESS MARK                          │  ← верхняя треть
│   extra-condensed ALL-CAPS Anton #FFD400    │     ТОЛЬКО буквы
│                                             │
├─────────────────────────────────────────────┤
│                                             │
│          детализированная сцена             │  ← нижние 2/3
│          один герой, один свет              │
│                                    [27:00]  │  ← правый низ пуст
└─────────────────────────────────────────────┘
```

Зафиксировано навсегда:

- формат **16:9**
- заголовок **всегда в верхней трети**, почти на всю ширину
- шрифт **Anton / Impact extra-condensed**, ALL CAPS
- цвет **жёлтый `#FFD400`**, плоский, лёгкое золотое свечение можно,
  без 3D и без радуги
- кегль огромный: 2–5 слов читаются на телефоне (~120 px ширины)
- 1 строка на два слова, 2 строки на три–пять
- картинка **детализированная**, photoreal, высокий контраст
- база тёмный charcoal / navy, один источник света
- лиц в камеру нет
- правый нижний угол (~180×72 px при 1280×720) пуст под тайм-код YouTube
- никаких стрелок, кружков, второго текста, логотипа канала, UI

Паттерны (`object` / `scene` / `silhouette` / `split` / `tension`)
живут **под** этой сеткой. Нельзя уводить буквы вбок, вниз или в центр
«потому что так лучше читается кадр».

Две обложки ролика — два разных паттерна и два разных хука. Сетка одна.

---

## Зачем это отдельно

YouTube сначала показывает превью маленькому срезу. Если CTR ниже
среднего по нише — ролик перестают крутить. В безликих history / true
crime сильный кадр даёт порядка 8–12% CTR, ниже ~3% тест обрывают
(Noodle Tomato, 2026; Alan Spicer, 2026). Ориентир «здорового» канала
4–8%; судить надо по своей базе.

Большинство просмотров — телефон. Рабочий размер превью в ленте
**~120–160 px по ширине**. Буквы огромные и всегда на одном месте: зритель
узнаёт канал до чтения title.

---

## Пять свойств кадра, которые двигают клик

1. **Одна мысль за полсекунды.** Один герой. Максимум четыре элемента.
2. **Контраст важнее палитры.** Светлый предмет на тёмном. Лица нет —
   контраст обязателен.
3. **Мало текста, и он не повторяет title.** 2–5 слов. Title несёт тему,
   хук на картинке — дырку, которой в title нет.
4. **Любопытный разрыв, который ролик закрывает.** Показать вопрос, не
   ответ.
5. **Узнаваемый бренд.** Один шрифт, один жёлтый, одна сетка. Менять
   кадр и хук; не менять буквы и место букв.

---

## Паттерны (герой под сеткой)

- **object** — один артефакт в упор.
- **scene** — киношный общий план одного места. Не коллаж.
- **silhouette** — фигура спиной или в тени + одна улика в свете.
- **split** — then / now одной вещи. Стрелку не рисовать. Сплит — в нижних 2/3.
- **tension** — одна «неправильная» деталь: сорванная печать, пустой
  постамент, столб без креста.

---

## Что в промпте модели

Модель рисует картинку вместе с жёлтым текстом. Промпт обязан:

- назвать сетку: 16:9, upper third empty for title, scene below, bottom-right clear;
- назвать паттерн и одного героя по имени;
- потребовать контраст и детализацию;
- вписать хук кавычками, Anton, `#FFD400`, «читается с 120 px», locked to the upper third;
- запретить второй текст, стрелки, лица в камеру, бежевый AI-грейд.

Каркас по умолчанию держит `pipeline/covers.py` (`SCENE_LOCK` + `TYPE_LOCK`).
Свой `cover_prompts` без верхней трети или без жёлтого хука дописывается
автоматически.
